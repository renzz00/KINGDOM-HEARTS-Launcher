KINGDOM HEARTS Launcher - installation
======================================

One launcher for the Steam versions of the KINGDOM HEARTS games
(1.5+2.5, 2.8, III, Melody of Memory) and the 358/2 Days native PC port.

REQUIREMENTS
- Windows 10 (version 1803 or newer) or Windows 11. Nothing else to install.
- The Steam version of the games. The Epic Games version is not supported.

INSTALL
The launcher is meant to sit next to your games, in the same steamapps\common folder:

    Default Steam install:
      C:\Program Files (x86)\Steam\steamapps\common\KINGDOM HEARTS Launcher\
    Another Steam library (use the one that holds your games):
      D:\SteamLibrary\steamapps\common\KINGDOM HEARTS Launcher\

    steamapps\common\
      KINGDOM HEARTS ...                  (your game folders, untouched)
      KINGDOM HEARTS Launcher\            (this folder)
        KINGDOM HEARTS Launcher.exe
        launcher_config.json              (created on first run)
        INSTALL.txt
        LICENSE.txt

1. Extract the whole zip. Do NOT run the exe from inside the zip.
2. Move the extracted "KINGDOM HEARTS Launcher" folder into your steamapps\common
   folder, as shown above. (To find it: in Steam, right-click a KINGDOM HEARTS game,
   Manage, Browse local files, then go up one folder.) Steam ignores folders it
   doesn't manage, so this doesn't interfere with updates.
   You can also skip this step: if you run the launcher from somewhere else, it offers
   on first run to move itself there (the folder is pre-filled; you can change it).
3. Run "KINGDOM HEARTS Launcher.exe".
   If Windows SmartScreen shows "Windows protected your PC", click "More info",
   then "Run anyway". The exe is not code-signed, so Windows warns about it.

FIRST RUN
4. Because the launcher is next to the games, it finds the games folder by itself.
   Open "Launcher Config" to check which collections it found (games it can't find
   are greyed out), or to change the folder if you put the launcher elsewhere.
5. Melody of Memory: set its exe under "KINGDOM HEARTS Melody of Memory executable".
6. 358/2 Days native port (optional): set its install folder or exe (default
   C:\Program Files\Kingdom Hearts 3582 Days) and tick "Use the native PC port".
7. Select a game and press Launch.

SETTINGS
- Saved in launcher_config.json next to the exe. If that folder isn't writable, they
  go to %LOCALAPPDATA%\KINGDOM HEARTS Launcher\launcher_config.json instead.

CONTROLLER
- Left stick / D-pad: move. A (Cross): launch. X (Square): open the config. Y (Triangle): open the OpenKH Mod Manager.
- In the config: A toggles or presses, B (Circle) goes back.
- Picking paths needs a mouse and keyboard. Works with XInput and DirectInput pads.

ADD TO STEAM
- On first run the launcher offers to add itself to your Steam library, with its
  artwork, so you can start it from Steam, Big Picture and your controller. Press
  "Add to Steam" (A on a controller). It is only asked once.
- If Steam is running, the launcher closes it cleanly and starts it again afterwards,
  so save any game you're playing first.
- To do it later, or again after moving the launcher folder, use "Add this launcher
  to Steam" in Launcher Config. The Steam entry points to the exe's current location,
  so do the install step first.

UPDATING
- Replace "KINGDOM HEARTS Launcher.exe" with the new one. Keep launcher_config.json
  to keep your settings.

UNINSTALLING
- Delete the folder. To remove the Steam entry, remove it from your library as for any
  non-Steam game.

TROUBLESHOOTING
- Controller stops working once a game starts (a PlayStation pad's light may turn plain
  red): keep Steam Input the SAME for the launcher and the games. In your Steam library,
  right-click the launcher (and the game), Properties, Controller, Override, and pick
  the same choice for both (both on, or both off). On + off together does not work.
- A game is greyed out: check the games folder in the config.
- Wrong exe picked for the Days native port or KINGDOM HEARTS III: browse to the exe
  directly (Days), or add it to "ExeOverrides" in launcher_config.json (see README).
- "Add to Steam" says Steam didn't close: quit Steam fully (also from the tray icon)
  and try again.
